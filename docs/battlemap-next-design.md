# GM Play standee interface

Next design task for Battlemap Studio. Design a single GM Play standee interface covering:

- Combat actions and rolls from linked Planner and imported D&D Beyond stat blocks.
- Status conditions and quick condition changes.
- A new targeting hotkey, with the key and targeting interaction to be decided during design.
- Connections to Battlemap chat for rolls and action feedback.

The Image Manager can also supply images for a future player handout workflow with explicit GM sharing.
